| 虚拟形象 | 角色与空间 | 头像色块选择、昵称、介绍、兴趣词、空间名称并实时生效 |

## 生产实现时必须替换的模拟层

| 当前模拟 | 生产要求 |
|---|---|
| localStorage 世界状态 | 所有长期数据通过服务端 Feishu Repository |
| 本地 rawEvents 数组 | 内存缓冲、IndexedDB 暂存、5-15 秒批量提交、幂等与重试 |
| CSS 视频占位 | 飞书云空间视频、预览视频与封面，按可见性懒加载 |
| 任意账户输入可进入 | 服务端 Argon2id 或 bcrypt、HttpOnly Cookie、Session 和失败次数 |
| 人工重置提示 | 管理员核验、一次性令牌和审计记录 |
| 本地 NPC 计时器 | AuctionRepository 中明确 bidder_type=npc 的服务端记录 |
| 本地隐私切换 | 用户表、研究同意版本、退出时间和匿名化删除工作流 |
| 原型维护簿 | 独立管理员权限、审核队列、导出和实验配置 |

## 仍需用户或外部条件才能进入生产的内容

- 飞书应用凭证、Bitable Base 与云空间目录
- 正式视频素材及封面
- 使用条款和隐私政策的正式法律文本
- 研究项目名称、伦理审批信息和联系人
- 生产域名、Cookie 策略与部署环境
- 推荐权重、实验样本量和结束规则

## 不实现的内容

- 真实支付、购买、退款与真实授权
- 实时多人位置同步
- 战斗、排行榜、签到和任务中心
- NPC 冒充真人
- 强制世界事件或未完成压力
