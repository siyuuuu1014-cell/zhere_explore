# Zhere 正式界面 4 · v15 流程完整性审查

审查时间：2026-08-10

## 结论

当前版本不是“所有流程都已打通且完善”的生产版本。它已经形成一套覆盖面较高、可在单浏览器内体验的前端原型；但账户安全、服务端持久化、跨用户同步、正式视频资产、事件可靠上报、后台治理与自动化测试仍未形成真实闭环。

真实支付按产品范围明确不实现，因此不计为缺口。

## 代表性流程

1. 入口与身份选择：界面完整；登录、注册与会话为本地模拟。
2. 进入开放世界与新手引导：可用，移动、附近行动、图鉴、发布、手账与回家入口清晰。
3. 视频详情：播放入口、点赞、收藏、标签、留言、素材对照、需求关联与竞价入口齐全；预置公共视频仍是占位播放。
4. 需求闭环：发布、公告树、草稿/关闭管理、文字或视频回应、双向关联已在本地状态中闭环。
5. 虚拟竞价：说明、余额、植物热度、提价与放弃均可操作；只作用于本地模拟状态。
6. 家园循环：采集、体力、开荒、翻土、播种、浇水、跨天、建造与副本摆放的前端循环已经存在。
7. 治理与研究：有曝光、实验、审核和导出界面，但页面明确标注为管理员原型；尚未连接 Feishu Repository。

## 已打通（单浏览器本地原型）

- 进入世界、移动探索、区域与附近物件提示
- 图鉴与玩法说明、新手引导、快捷键与行动盘
- 视频详情、互动、标签、留言、收藏、素材关系
- 需求发布、草稿、关闭/恢复、删除、文字/视频回应和双向关联
- 本地视频上传、IndexedDB 保存和浏览器回放
- 虚拟币与虚拟竞价
- 采集、体力、跨天再生、家园开荒/种植/建造
- 探索手账、背包、个人空间、隐私与管理员界面

## 部分实现

- 身份系统：只有 `login-mock` / `register-mock` 和本地 Session 标记。
- 视频链路：本地上传可播放；公共预置视频仍是占位片段，没有云端资产、转码和内容审核。
- 多人/社交：能看到模拟角色和公共内容，但没有真实跨用户同步。
- 数据研究：事件记录在浏览器状态中，没有可靠的批量提交、幂等、失败重试和服务端实验分组。
- 隐私与治理：有完整界面和说明，但导出、删除、审核与参数调整主要是原型动作。

## 尚未打通的生产闭环

- Feishu Repository / 飞书多维表格与云空间的数据层
- 密码哈希、HttpOnly Session、找回密码、冻结/解冻等真实账户安全
- 跨设备、跨浏览器和跨用户的一致持久化
- 事件缓冲、IndexedDB 暂存、5–15 秒批量提交、幂等重试与世界状态恢复
- 真实后台审核、隐私导出/删除、推荐和实验配置
- 单元测试、集成测试、端到端测试、异常/离线恢复测试和完整移动端回归

## 证据

- `prototype.js` 使用 `localStorage` 键 `zhere-v8-design-state`，上传文件使用 IndexedDB `zhere-local-media`。
- 登录和注册写入 `login-mock` / `register-mock`。
- 公共视频状态文案为“正在播放占位片段”。
- 管理员操作提示“已模拟”，并明确写明正式实现须经过服务端 Feishu Repository。
- 目录中未发现真实后端、Repository、服务端 API 或自动化测试工程。

## 推荐优先级

1. 先接真实账户、Session 与 Feishu Repository，让内容、关系、需求、竞价、家园和事件成为服务端事实源。
2. 再完成公共视频资产、上传转码、审核、播放与授权元数据链路。
3. 补事件可靠上报、实验配置、隐私导出/删除和后台治理。
4. 建立核心路径 E2E、移动端断点、离线恢复和刷新/跨端一致性测试，之后才可称为“流程完善”。

## v16 基础链路实施记录

2026-08-10 已完成第一阶段服务端改造：

- 账户：Argon2id 密码哈希、HttpOnly/SameSite Session、注册、登录、退出、重置申请、失败登录计数与临时冻结。
- 服务端数据：世界状态改由 `/api/world-state` 和 Repository 持久化，刷新后可恢复；旧 localStorage 仅作一次迁移。
- 视频资产：视频上传到媒体 Repository，通过受 Session 保护且支持 HTTP Range 的 `/api/media/:id` 播放。
- 事件上报：浏览器内存 + IndexedDB 暂存、8 秒/20 条批量提交、关键事件立即提交、页面离开前提交、服务端 `event_id` 幂等。
- 飞书：已提供多维表格与云空间 Repository 适配器及生产配置检查；实际飞书联调仍需要项目 App ID、App Secret、表 ID 与云空间文件夹 token。
- 测试：账户、世界状态、事件幂等和视频上传/读取的 5 项自动化测试通过；浏览器完成真实注册、刷新恢复、上传发布和播放回归。
